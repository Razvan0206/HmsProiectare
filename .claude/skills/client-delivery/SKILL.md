# Client delivery

Read `guidelines/08-delivery-and-client.md`.

- Message first (WhatsApp with link + 20-30 s screen recording), call after the client saw it; call directly only if the user knows the owner.
- Before sending: the public URL opens from a phone on mobile data without a login; first visit and returning visit both fine; placeholders and temporary photos visibly marked; site `noindex`.
- A 20-30 s demo video can be made with plugin **brag** (`/brag-slim` is the lean one); review it before sending and tell the user if it pulls external assets or tools.
- Give the user the Romanian message adapted to the client (template in the guideline); no price in the first message.
- Launch and handover: use the checklists in the guideline; write feedback and decisions into the project CLAUDE.md.
