# Niche guidelines

1. Map the business to a file in `guidelines/niches/` (see its README). Read the whole file.
2. No match: copy `guidelines/niches/_TEMPLATE.md`, fill it from this project, mark every unverified claim, add a row to `guidelines/niches/README.md`.
3. Apply: primary conversion, section order, "collect from the client" checklist (ask once), schema type, compliance notes, anti-patterns, definition of done.
4. Never fix a palette from a niche file; derive identity from the client's own materials (`guidelines/04-design-rules.md`).
5. Regulated niches: guidance only; tell the client to check wording with a professional.
6. After the project: update the niche file and its maturity status.
