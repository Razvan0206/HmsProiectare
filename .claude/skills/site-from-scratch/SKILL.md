# Site from scratch

1. Read `guidelines/00-START-HERE.md` and `guidelines/03-workflow.md` fully. Run `node scripts/doctor.mjs`.
2. Follow the 10 phases in order; state the gate result after each phase in one line.
3. Phase routing: niche -> skill `niche-guidelines`; materials/photos/logo/video/reviews -> `client-assets`; identity -> `ui-ux-pro-max` + `design-taste-frontend` + `design-references`; verify -> `site-audit`; deploy -> `ship-site`; demo -> `client-delivery`.
4. Always on: ponytail + caveman (chat only). Chat Romanian; site copy Romanian; never invent facts; placeholders visibly marked.
5. Ask first: global installs, copying from repos you do not own, publishing client data, force-push, public repos, invitations.
6. At the end write lessons back into `guidelines/` (niche file + `09-lessons-raf-gym.md` or a new case study).
